7.1.1
Рассмотрим возможные отношения между концами 2 интервалов (x1, x2) и (y1, y2):
1. x2 -> y1 (очевидно, что x1->x2->y1->y2). Тогда по определению X->Y.
2. y2 -> x1 (очевидно, что y1->y2->x1->x2). Тогда по определению Y->X.
3. y1->x1->x2->y2 / y1->x1->y2->x2 / x1->y1->y2->x2 / x1->y1->x2->y2 - здесь ни одно из условий y2 -> x1 / x2 -> y1
    не выполняется, следовательно, по определению, X и Y пересекаются

7.1.2
Иррефлексивность: X определяется как (x1, x2)б x1->x2. Для верности рефлексивности X->X по определению необходимо, чтобы
    правая граница X предшествовала левой: x2->x1, что не верно по определению тотального порядка ивентов. Значит, never true that X->X.

Антисимметричность: если X->Y, то по определению x1->x2->y1->y2. От противного: пусть верно, что Y->X. Однако тогда по определению
    необходимо, чтобы y2->x1, что неверно из определения X->Y - противоречие. Значит, имеет место антисимметричность: If X -> Y then not true Y -> X

Транзитивность: пусть X->y и Y->Z, тогда по определению предшествования x1->x2->y1->y2 и y1->y2->z1->z2. В силу транзитивности -> имеем:
    x2->y1 && y1->z1 => x2->z1. Значит, по определению предшествования, X->Z, то есть имеет место транзитивность If X -> Y and Y -> Z then X -> Z

Пример: пусть есть 3 события такие, что a->b->c и (a, b)=X != Y=(b, c). В силу иррефлексивности ивентов неверно, что b->b, а по ассиметричности, что c->a.
    Значит неверно, что X -> Y или and Y -> X.
